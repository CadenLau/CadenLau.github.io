06 / Gameplay systems · In development

DGA Studios

Working on an upcoming student-developed game, I built a reusable notebook system that gives designers control over interconnected questions and puzzle progression.

06 / PROJECTGameplay systems
Role
Gameplay programmer
Team / date
Development in Games Association · 2026–present
Tools
Unity · C#

The problem

Notebook questions and puzzle dependencies need to be created and updated throughout development. Hardcoding each question would make content iteration dependent on programming support.

The system

I developed a reusable Unity notebook interface with configurable questions, evidence submission, prerequisite-based question chains, and puzzle-driven progression. Designers can author and connect question content in the Unity Inspector without modifying code for each new question.

Designer authors content→Configure dependencies→Player unlocks progression

Why it matters

The system separates content authoring from the implementation of the underlying gameplay rules. This makes it easier for designers to iterate independently, with an estimated dozens of hours of future development work saved.

Because the project is in development, this page focuses on my tooling contribution rather than unreleased narrative or puzzle content.
